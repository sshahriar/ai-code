# Welcome: Building a 3D Game with Cursor AI

## At a glance
Day one skips the long intro and gets you shipping. Install Cursor, open a fresh folder, and prompt the agent to build a simple browser-based 3D FPS so you feel AI-assisted coding working immediately. Deeper agent theory, curriculum, and logistics come later; today is a playful exception before business-focused projects.

## Key takeaways
- Learn by building first; framing and theory land better after you’ve shipped something.
- Cursor is the day-one tool (approachable, free trial); later you’ll use multiple AI coding products.
- Setup: download from cursor.com → install (Mac: Applications; Windows: defaults + PATH) → sign in → open a project folder (e.g. `projects/instant`).
- UI is VS Code–like: files left, editor center, agent chat right—use **View → Appearance** if panes are missing.
- Prompt clearly (3D FPS arena, one AI opponent, arrows + space); approve tool use; expect non-deterministic results that differ from classmates.
- Free trial is enough; keep prompts concrete; use course resources if install/UI details change.

## You will learn
- How this course approaches learning (build first, theory second)
- How to download, install, and sign in to Cursor on Mac and Windows
- How to open a project folder and orient yourself in the Cursor UI
- How to prompt the agent to generate a playable web game
- What to expect from non-deterministic AI coding sessions

## Bottom line
Get Cursor running, open an empty project, and let the agent generate a small 3D shooter so you experience “AI writes real code” on day one—then the course shifts to structured, business-impact work with stronger agentic practice.
